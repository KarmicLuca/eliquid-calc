# eLiquid Calculator

This app helps DIY mixers plan out e-liquid recipes. Enter the goal volume, VG/PG ratio, nicotine strength, and flavor percentage to see the exact milliliter/gram amounts required for each component. A nic-base calculator shows how much nicotine base to add to hit a desired concentration, and the presets feature lets you recall common mixes or store your own favorites (saved to local storage).
